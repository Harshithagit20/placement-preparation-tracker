# Placement Preparation Tracker

A responsive browser-based dashboard for organizing placement preparation, tracking study tasks, and recording solved DSA problems.

## Features

- Add and delete study tasks.
- Categorize tasks by Java, DSA, Projects, Aptitude, or Resume.
- Mark tasks as complete and view progress.
- Set a daily task goal.
- Record solved DSA problems.
- Save progress in browser local storage.
- Responsive layout for desktop and mobile.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a task and refresh the page to verify local storage works.

No build tools or dependencies are required.

## Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings** → **Pages**.
3. Under the build/deployment settings, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear on the Pages settings screen.

## Data and privacy

This project stores tasks only in the current browser's local storage. Data is not synced between devices or browsers. Avoid entering sensitive personal information.
